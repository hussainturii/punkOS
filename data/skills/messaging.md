# Messaging

Locate the exact requested app and recipient using visible controls. Search the
name, inspect the results, and disambiguate if several contacts match. Confirm
the conversation header before typing. Never infer a recipient from a document
container's name or an unread-message count.

Check the full recipient and exact message before sending. Sending is a
consequential action and must go through the app's confirmation policy.
Verify the outgoing message in that conversation after sending. A launch,
contact click, draft, or empty composer does not establish successful delivery.
If the accessibility tree is shallow and vision is unavailable, stop with an
explicit observation blocker instead of repeatedly clicking the container.
