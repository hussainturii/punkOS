# Calculator: input and verify

Reuse the foreground Calculator. Opening it does not complete a calculation.
Read its display before acting. For a new calculation use the observed Clear
button once to remove old input. Do not clear an intermediate result.
Type one number at a time; use observed operator buttons between numbers.
When the last action entered a number and that number is now displayed, the
next arithmetic step is to CLICK the requested operator, not type another number.
Wait until the expression shows that operator before entering the next operand.
The display is read-only; numeric type actions must use target_tag=null.
Do not paste an entire expression: Calculator is not a text editor.
After every action read the display/expression to determine what actually changed.
If numeric typing leaves the display unchanged, use the observed digit buttons
instead. Do not append another copy of the number without checking the display.
Never repeat an unchanged input method indefinitely. If neither keyboard nor
observed buttons work, report the focus/input limitation and stop.
Press the observed Equals button when required and verify the displayed result
against the complete requested calculation. A sent-input receipt is not proof.
Respect mouse-only instructions: use buttons for digits as well as operators.
