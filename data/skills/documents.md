# Document work

Read every required source and keep observed facts separate from suggestions.
Record which file supplied each decision. Preserve sources by working in a new
document or an explicitly requested copy. Never clear a source to create a copy.

For a new multiline draft, prefer one type action containing the entire literal
body with JSON newline escapes. Do not use SendKeys macros such as {enter}.
A targeted type action replaces the selected editor content; do not use it to
append a second line unless the text includes the complete intended document.

Before saving, verify the active document, complete destination path, filename,
and any existing-file collision. Cancel an overwrite of a protected source.
Repeated Ctrl+S is not recovery. Inspect the dialog and change strategy.
When the original must remain unchanged, never press Ctrl+S on its edited tab.
Go directly to Save As (Ctrl+Shift+S) and the separate requested output path.
Replace and Replace All are different controls: do not call a button Replace All
unless that is its observed label. After each replacement inspect the document
and remaining matches; stop replacing when every requested occurrence changed.
In Notepad, the first Replace click can select a match without changing it.
Selection and caret movement are not replacement evidence. If the document still
contains the requested old text, continue replacement before opening Save As.
Use the observed Replace dropdown to locate Replace All when available; never
invent a Replace All target or infer completion from a successful click receipt.
When Save As closes and the editor returns with the saved filename, advance
past saving. Enter in the editor inserts a newline; it cannot confirm a closed
dialog. To reopen, use Ctrl+O, observe the Open dialog, enter the exact saved
path in its filename field, and open it. Never repeat the write/save recipe
from the beginning just because it is supplied as plugin guidance again.
Reopen the saved output and compare the entire requested content. Do not claim
success from an unsaved tab, a keystroke receipt, or a filename alone.
After the exact output has been reopened and its content satisfies the goal,
report the requested facts and finish. Do not repeat Save or Open unless a new
edit or a concrete content mismatch requires it. Find/Replace field text is
not document content; an old search term remaining there is not an unfinished edit.
# Opening the intended document

When the goal supplies an existing file to open before editing, open that exact
path first. Do not start a replacement recipe in whichever tab was already active.
An ordinary Open dialog is an expected intermediate state, not a task failure.
If the observed dialog exposes an enabled File name edit field and an Open
button, type the requested full path into that field, then activate Open in
the next step. Avoid Search Box and the Files of type dropdown. Inspect the
result: handle a file-not-found message if present, or verify the intended
document title and contents before beginning edits. Never close a normal Open
dialog merely because it blocks the editor underneath it. If controls are
temporarily missing, wait once and observe again; do not invent targets.
